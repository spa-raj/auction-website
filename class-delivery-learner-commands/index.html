Stage 2 — The race condition

5. Find the vulnerable sequence

Open Part 2 in VS Code:

code ~/codex-course/workshop/part-2-create-auction-and-bid

Find the bid handler, typically in server/src/app.ts. Search for:

INSERT INTO bids

Expected: the handler follows this sequence:

Read current price → Validate bid → Insert bid

Two requests can both read the same old price before either inserts its bid. Sending one bid, waiting, then sending another does not expose this; the requests must overlap.

6. Start a new Codex chat

Keep workshop selected. Leave Part 2 running.

Paste into the new chat:

Inspect the bidding endpoint in part-2-create-auction-and-bid.
